# Baseline run

The recorded output of the single-split baseline described in
[../../docs/RESULTS.md](../../docs/RESULTS.md). This is the one directory under
`results/` that is committed; everything else here is regenerated by a run and stays
out of git.

| File | What it holds |
|---|---|
| `confusion_matrices.json` | Per-model confusion matrices, the protocol that produced them, and the reference paper's published accuracies |
| `../../assets/baseline_run/training_history.json` | Per-epoch loss and accuracy for all three models |

Both are inputs to `scripts/render_figures.py`, which produces every figure in the
README. Charts are generated from these files rather than pasted in, so a number and
the chart drawn from it cannot drift apart — CI rebuilds the figures on every push.

The matrices are stored as counts rather than as derived rates, because rates are
lossy: sensitivity 0.98 does not tell you whether it came from 41 of 42 or from 490 of
500, and on a 42-case positive class that difference is the whole story.
`scripts/render_figures.py` expands them back through the package's own
`metrics.operating_point_metrics`, so the figures and the library agree by
construction.

No ROC-AUC is recorded for this run: it retained hard predictions only, and
threshold-free metrics cannot be recovered from a confusion matrix. The benchmark
harness therefore persists per-image probabilities to `results/<name>/test_scores.npy`.
